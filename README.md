# RTM en direct

R.T.M Radio Télévision Moba (Tanganyika, RDC) en direct sur le téléphone : le direct de la chaîne, « en ce moment », « à suivre » et le programme du jour.

Application installable sur iPhone (Safari → Partager → « Sur l'écran d'accueil ») et Android (Chrome → « Installer l'application »).

Application développée par l'ingénieur BARUCK TCHANSA PAUL.
